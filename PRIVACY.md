# Message Age for FunPay privacy policy

Message Age calculates how much time has passed since a FunPay message was sent. It runs on HTTPS pages at funpay.com and www.funpay.com.

The extension reads the timestamp under your pointer or the text you select on FunPay to check whether it contains a timestamp. It processes this information locally to display the elapsed time. It does not save that text or send it to the developer, FunPay, or any other party.

The extension stores your hover preference, numeric date format, and time offset in local extension storage. These settings stay in your browser. Uninstalling the extension removes its local settings.

The extension makes no network requests and uses no analytics or advertising. It does not sell or share user data. Its use of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

For questions, use the [project’s GitHub issue tracker](https://github.com/Rekauchi/message-age-funpay/issues).
